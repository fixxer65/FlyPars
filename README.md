# Pobeda Price Monitor (Android)

Приложение-парсер цен на авиабилеты «Победа» (flypobeda.ru).
Мониторит все направления вылета **из Москвы** (хаб MOW: VKO, SVO, DME, ZIA)
и **из Минска** (MSQ) на диапазон дат и показывает список направлений с ценами по дням.

## Как это работает
Вместо хрупкого парсинга HTML используется тот же JSON-API, что и страница
«Лучшие предложения» на сайте:

```
GET https://site-api.flypobeda.ru/best-offers/multi?locale=ru&departure[0]=MOW|MSQ&dates[0]=YYYY-MM-DD
```

Запросы по всем дням периода выполняются параллельно (OkHttp + Kotlin Coroutines),
результаты склеиваются в карточки «направление → цены по датам», минимальная цена подсвечивается.

## Структура проекта
```
app/src/main/java/ru/pobedamonitor/
├── MainActivity.kt              # UI на Jetpack Compose (Material 3)
├── data/PobedaRepository.kt     # сетевой слой / парсер API
└── ui/PobedaViewModel.kt        # состояние экрана, загрузка
```

## Возможности UI
- Переключатели хаба: Москва / Минск (можно оба сразу);
- Выбор даты начала и глубины периода (7 / 14 / 30 дней);
- Список карточек направлений: город прибытия, IATA-код, минимальная цена;
- Лента «дата + цена» внутри каждой карточки, самая дешёвая дата подсвечена красным;
- Кнопка обновления, индикатор загрузки, время последнего обновления.

## Сборка
Откройте проект в Android Studio (Hedgehog+), дайте Gradle скачать зависимости
(AGP 8.5.2, Kotlin 2.0.20, Compose BOM 2024.09) и соберите:

```
./gradlew assembleDebug   # APK: app/build/outputs/apk/debug/app-debug.apk
```

minSdk 24 (Android 7.0), targetSdk 34. Разрешение: INTERNET.

## Примечание
API является внутренним и может измениться — при смене формата правьте только
`PobedaRepository.parseDay()`. Используйте данные как ориентир: финальные цены
проверяйте на сайте при бронировании.
